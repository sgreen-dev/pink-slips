# Changelog

Every change to Pink Slips, by the day it landed. Dates are commit dates, newest first. Each line ends with the commit that made the change, so anything here can be traced in the history. A phase entry names its phase from `BUILD_PLAN.md`; the commit that marks a phase done is listed with it. Every commit adds a line here under its day.

## 2026-09-11

- Backlog Q53, the stylesheet's doubled rules. Six selectors that were written in two places are written once: the page body, the brand, the dealt-hand note, the rules dialog, and the prompt and button row under the board, whose reserved height now sits with the rest of their layout instead of seven hundred lines further on. The two that stay split, the mod card and the card back, point at each other from both ends, and the mod card is out of the reduced-motion list for a transition it never had. Nothing on screen changes: every computed value on a test page came out the same before and after, at three widths with Reduce Motion off and on, apart from that one dead entry. (the commit that records it)
- Backlog P6, the fonts: the game serves its five typefaces itself instead of loading them from Google. A visit used to reach two more origins, wait on three Google stylesheets before it could paint, and hand the player's address to Google on every load; now it asks no one else for anything. `npm run fonts` fetches every face and subset exactly as Google serves them, so nothing renders differently, and writes each family's licence beside its files. The two cut-down faces, the wordmark and the digits, are small enough that the build folds them into the stylesheet. Measured before, over five cold loads on a throttled connection: first paint at about 1.1 s and the last font in at about 4.6 s, from three Google stylesheets and five font files. The same measurement, taken once this is live, gets its own entry. (05ee55a)
- Backlog D7, D8, Q48 and Q51, the docs and tooling leftovers. The build plan has the three phases the design doc already cited, 45 to 47, each with its commit, and the button system's section cites phase 47 instead of repeating 32. The eleven changelog lines that never got their commit hash have one now, each found by searching the history for its own words. The art credits cache no longer carries the retired Demon 170, and the art script drops any car that leaves the roster. And the simulator's six balance targets live with the other tunables, where the design doc always said they were, with the two it never listed added to its table. Filling the hashes also turned up three places that named the working-instructions file kept outside the repo, against the repo's own rule: a changelog line, a backlog note and a test comment. Each states the rule now instead of naming the file. (5a35ac5)
- Backlog A8, A9, A10, Q52 and U37, the screen leftovers. Opening a pack in the collection announces one line to a screen reader, how many cars and mods and which are new, where it used to read out all five cards, some fifty fragments in a row. The player dialog makes the page behind it unreachable while it is open, so Tab can no longer walk out of it into the start screen. Opening the last pack in the pop-up after a match hands focus to Done instead of dropping it. The credits list tries again the next time it is opened after a failed load. And a card leaning under the pointer no longer snaps flat when it is picked: the lean is marked in a way React never overwrites. (551392c)
- Backlog Q49, Q50, G18 and G19, the engine leftovers. A race now always ends: wear used to be able to stop a car dead at 10 points, so two cars worn out by Bad Tune and Redline could stall a race for ever, and now a worn car always covers at least a tenth of its distance. That is a new tunable, `wearFloor`, and no simulated match reaches it, so the balance report is unchanged to the digit. The online client refuses a match from the server whose phase or turn step the engine does not know, instead of letting it make the board throw. A pack's car slot can no longer fall back to a mod, and a test holds every tier the odds can roll to having cars. And the three rules about the order of an advance that the design doc spells out after its seven steps finally have tests. (d2aef17)
- Backlog Q42 to Q47, the deploy and tools group. The deploy workflow now ends by checking the workers: once the site is live it fails if either worker is missing a change to its own code, and names the command to run, while a push that changed only the site passes. Each of its jobs holds only the permissions it uses, so dependencies are no longer installed beside a token that can publish the site, and no checkout leaves its token on disk. `npm run dev:stop` stops a process only when it runs a file inside this repo, where before a tool started elsewhere could be stopped for being handed a path here, and it lists `wrangler dev` without stopping it, since nothing says whose that is; its rules are tested now. `vite preview` is allowed by both workers, which share one list of where the game is served from; the CORS preflight includes the admin route's DELETE; and the lint rule that keeps UI code out of the workers covers the workers themselves. (70757d6)
- Backlog Q41, S19, S20, S21 and S22, the server group. The server code that runs on Cloudflare can finally be tested: its objects import a module that only exists inside a worker, so the tests now load a small stand-in for the platform, and the first of them drive the real room object through a whole stakes match. A room that expires now closes its sockets as it goes, where one tab left open could bring a forgotten room back with a fresh day. A message that changes nothing no longer rewrites the whole match to storage, and each connection gets a generous budget of messages, so no client can make a room work faster than play does. The queue no longer stalls for everyone because one connection arrived without its record. And the limit on new players per address counts an IPv6 client by the block it holds rather than by each address it rotates through, keeps only a hash of the address, and forgets it after the hour, where before every address that ever made a player stayed in storage for good. (55d5596)
- Backlog S16, S23 and S24, the stakes group. A stakes match online now moves a car only out of a collection that holds it. A keepsake stays with whoever holds it, the winner as much as the loser, where before a winner's keepsake captured in a race stayed put and was handed to the loser as well; a car its owner does not have is no longer copied into the captor's collection; and a side that raced a car its account does not own takes nothing, while whatever of its own it staked still goes to the other side. That closes the hole a client written for the purpose could use to join a stakes room with cars it never opened and win real ones; the room now reports each seat's garage with the result so the directory can check. Separately, the browser's own collection loader holds a stored record to the same checks the service uses, so a damaged record with negative or fractional counts is replaced as intended, while a record from before finishes existed still loads. (dc6979b)
- Backlog U29, U33, U34 and A11, the match screen group. In an online match, arming Leave put Concede where Leave had been, so a double tap conceded a ranked game; Stay comes first now, as every other confirm pair in the game already did. A new match no longer scrolls itself down to the track a beat after it opens: the turn-end camera move ran once on arrival, before any turn had ended. The match log stops replaying its slide-in on every line each turn once it passes eight entries; only the new line slides in, which is what the animation was written to do. And a second refused play no longer knocks focus off the notice's OK button: the notice replays its fade in place instead of being rebuilt. Each fix has a test that fails on the old code, one of them against a stand-in for the online room. (6f852fa)
- Backlog U30, U31, U32, U35 and U36, the stylesheet group, headed by the last high bug in the backlog. Reduce Motion switched off less than it claimed: its block sat in the middle of the stylesheet, and eight animations written below it — the action buttons rising, the log sliding, the finish flash, the race-end banner and its card, the pack reveal, and both card shimmers — kept moving, because a media query adds no weight and the later rule wins. The two reduced-motion blocks are one now, at the very end of the file, with the card-art fade added. The same mistake had left the phone spacing on the builder and collection titles doing nothing; it sits after its base now. The header buttons on the builder, collection, online and profile screens were a size bigger on a phone than the board's, from an old override that beat the small size on weight; it is gone and they match. The board's action row and the guide's buttons are spaced 0.4rem like every other row. A new test reads the stylesheet and fails on the two shapes behind all of this, and before-and-after readings from a real browser engine confirm every change. (e779ea4)
- Backlog S17 and S18, the two high security rows from the review. A finished online match's packs, rating and stakes cars no longer vanish when the call to the account directory throws: the room keeps the result and sends it again, the way it already did when the directory refused one. Sending again was only safe once the directory could spot a repeat, since an answer lost on its way back looks exactly like a report that never arrived, so each result is now named from the room's code, its seed and the match's number, and the directory applies a name once and remembers it for a week. The counting route turns away requests with no origin, a day holds at most 2,000 browsers so a script can fill one day and no more, and the counts prune themselves daily, including the list of first sightings, which nothing had ever pruned. No address is read for any of it. (f0464aa)

- Backlog U14, `npm run dev:stop`: it matches anything of ours now rather than a list of programs someone kept having to extend. Three times it was widened after the fact — vite, then wrangler and workerd, then http.server — and between each widening it answered that the machine was clean, confidently and wrongly, because a list of tools can only find what somebody remembered to add. The rule is inverted: anything running in node, python, deno or bun whose command line carries this repo's path is ours, whatever the tool. It deliberately stops short of matching any process under the repo, because an editor with the folder open carries that path too and the cost of a wrong match is killing an editor, where the cost of a missed one is a line of output; vitest and the script itself are carved out by shape. Alongside it, a cross-check that never acts: anything holding one of this repo's ports that the rules did not claim is printed and left alone, so the script can no longer imply an empty machine while a port is held.
