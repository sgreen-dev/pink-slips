# Changelog

Every change to Pink Slips, by the day it landed. Dates are commit dates, newest first. Each line ends with the commit that made the change, so anything here can be traced in the history. A phase entry names its phase from `BUILD_PLAN.md`; the commit that marks a phase done is listed with it. Every commit adds a line here under its day.

- Backlog P5, the room's writes: a seated message costs one storage write instead of three. The room wrote its snapshot, its expiry and its alarm every time, but only the snapshot changes that often — the expiry is always a day out and the alarm follows it whenever no turn clock is running. Proved against a local worker with two seats joined for real: the first message wrote all three, every message after it wrote only the snapshot. - Phase 38, backlog S6: the limit on new players from one address is now a limit. - Phase 37, backlog S5: the match generator is four words wide instead of one. It was mulberry32, whose whole state is a single 32-bit integer, and a player sees their own opening hand, which is the front of a shuffle of a deck they chose — so the state could be searched offline until it reproduced that hand and then run forward to read the opponent's deck and every coin flip left in the match. Online play zeroes the state in the view it sends, and that zeroing was only worth the width of what it hid: candidate states check at about 130 million a second on an ordinary laptop, so the old space fell in half a minute. The generator is now xoshiro128** over four words, a real match is seeded with all four from the platform's random source rather than one word expanded, and a rematch takes fresh randomness instead of the previous seed plus one, so reading one match no longer reads the next. A room snapshot written before this carries a number and is expanded rather than dropped, since rooms live a day. Balance is unchanged, checked at 40,000 matches on each generator. (a95733b)
