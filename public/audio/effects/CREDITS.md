# Sound effect credits

The effects in this folder were made by the owner for Pink Slips and are part of this
repository under its terms. The originals are WAV files kept by the owner outside the
repository; `scripts/audio/encode_effects.py` produces these MP3 copies. An effect with no
file here is synthesized by the game itself.

| File | Where it plays |
| --- | --- |
| advance.mp3 | A car's advance; pitch and level follow the distance |
| boost.mp3 | Playing a Boost |
| coin.mp3 | A coin flip |
| deflect.mp3 | A Sabotage that does not take |
| fuel.mp3 | Placing a fuel token |
| matchEnd.mp3 | A match ending |
| part.mp3 | Fitting a Part |
| raceEnd.mp3 | A race ending |
| sabotage.mp3 | Playing a Sabotage |
| shimmer.mp3 | A rare pull in a pack |
| shuffle.mp3 | A draw or a reshuffle |
| sparkle.mp3 | A pack reveal |
| stage.mp3 | Staging a car |
| stall.mp3 | An advance that cannot be made |
| yourTurn.mp3 | The player's own turn beginning |
