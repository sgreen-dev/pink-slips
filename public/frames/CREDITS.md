# Card frame credits

The artwork in this folder was supplied by the owner for Pink Slips and is part of this
repository under its terms. The sources are the PNG files in `game-images/frames/`;
`scripts/art/import_assets.py --kind frames` produces these WebP copies.

| File | Where it shows |
| --- | --- |
| back.webp | The card back |
| ev.webp | Frame of ev cars |
| jdm.webp | Frame of jdm cars |
| luxury.webp | Frame of luxury cars |
| mod-boost.webp | Mod card frame, boost |
| mod-part.webp | Mod card frame, part |
| mod-sabotage.webp | Mod card frame, sabotage |
| muscle.webp | Frame of muscle cars |
| offroad.webp | Frame of offroad cars |
| sports.webp | Frame of sports cars |
